Create a modern, professional, and mobile-friendly website for a project named "BikerAid" — an emergency response system designed for bikers. The goal is to help bystanders or first responders quickly access a biker’s critical medical and emergency information by scanning a QR code attached to the biker’s helmet.

🔒 Core Concept:
Bikers register and input their emergency information (name, blood group, diabetes/BP status, allergies, emergency contacts, etc.)

System generates a unique QR code

QR is printed and fixed to the helmet

In case of an accident, scanning the QR opens a public safety profile
